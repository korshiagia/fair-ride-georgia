## Mapping licence and data lineage implications

Google Routes standalone usage is documented, but use with non-Google maps is prohibited by the accessed service-specific terms. Its 30-day exception is **lat/lng values**, not blanket indefinite route/ETA/polyline storage. Place IDs have a separate documented exception. Distinguish customer-provided coordinates and approved own trip facts from vendor-derived geometry, labels, route duration and map screenshots; tag provenance and exact allowed retention in logs/events/backups as well as primary storage. This is a selected minimization design; counsel must approve the actual rights and privacy transfer model.

Mapbox temporary/permanent geocode rights do not automatically authorize Search Box or route storage. The published Search Box language list omits Georgian; “Europe” wording does not settle Georgian POI coverage. Its best-effort route exclusion can return a violation, so reject/review that output before treating it as legal. Android offline rendering supports limited packs, fetched by device from Mapbox; prebundling/redistribution is not permitted by the cited constraints. Offline rendering does not establish offline search/route/ETA. Vehicle-use licence language is material for the driver surface; exact application classification and executed order are prerequisites even to non-production API use where applicable. Do not start Mapbox API experiments under an assumed generic free tier.

Choose a coherent provider stack per displayed output. A provider switch preserves own permitted inputs and source-specific attribution, not old vendor caches. If Google licence/quality fails or long-term evidence cannot be retained lawfully, evaluate Mapbox with reviewed vehicle/retention terms or a contracted OSM-based stack with ODbL/licensing/update/operated SLA evidence; no self-hosted infrastructure is built or selected now. Fallback first exposes uncertainty/manual correction; no provider/API/offline option supplies city/airport permission.
